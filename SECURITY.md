# Security policy

This repository contains research implementations and samples. No version is supported for production accounts or a security service-level commitment. The Function broker design and older browser-extension spike are not supported signing services. The hardened Windows provider and browser extension are maintained in [`keyvault-passkey-provider`](https://github.com/nathanmcnulty/keyvault-passkey-provider).

## Reporting a vulnerability

Use **Security → Advisories → Report a vulnerability** on this repository's [security advisories page](https://github.com/nathanmcnulty/research-passkeys/security/advisories). Private vulnerability reporting is enabled. Please do not put exploit details, credentials, passkeys, tenant data, or private logs in a public issue.

Include the affected component and revision, expected and observed behavior, impact, and a minimal reproduction with all secrets and personal data removed. If the issue affects the provider repository, say so in the private report; the maintainers will route the fix to its authoritative source. There is no promised response time while these projects are experimental. The maintainers will coordinate disclosure and credit with the reporter where practical.
