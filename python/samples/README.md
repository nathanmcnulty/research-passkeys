# Python samples

Current Python samples:

- `entra`: local Entra registration and login examples over the canonical `passkey` library; its device-code example is historical and unsupported
- `keyvault-passkey-token-inspector`: inspects redacted OAuth/OIDC metadata after Key Vault-backed passkey authentication
- `okta`: Okta MyAccount and IDX browser-session registration/login examples

For current interactive Microsoft authentication, use a cached WAM/MSAL session or the normal OS/browser sign-in flow. Do not run the historical device-code samples.
